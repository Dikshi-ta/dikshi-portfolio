Project Case Study

Wake-Word SOS Activation System

An Android-based emergency assistance application designed to help users initiate an SOS workflow through voice-based wake words and shake gestures.

Project Type

Android Application / Safety Technology

My Role

Android Developer and UI/UX Designer

Platform

Android

Technologies Used

Kotlin, Android Studio, Android Services, Device Sensors and Voice Activation

1. Project Overview

The Wake-Word SOS Activation System is an Android-based emergency assistance application designed to simplify the process of initiating an SOS workflow during an emergency situation. The system explores voice-based activation through predefined wake words and shake-based activation as an alternative interaction method.

2. Problem Statement

During an emergency, users may not always be able to unlock their phones, open an application, or press an SOS button manually. This project addresses that challenge by exploring faster and more accessible ways to initiate an emergency assistance process using voice and motion.

3. Project Objectives

  • Provide a quick method to initiate an SOS workflow.
  • Support hands-free activation using a predefined wake word.
  • Provide shake detection as an additional trigger.
  • Offer a simple interface for emergency contacts.
  • Improve usability and accessibility during stressful situations.

4. Main Features

  • Wake-Word Activation: The application detects configured words such as "Help" or "Aura" and starts the SOS workflow.
  • Shake Detection: The system uses device motion data to detect a deliberate shake gesture.
  • SOS Workflow: After activation, the application begins the configured emergency-assistance process.
  • Emergency Contacts: Users can manage contacts intended to receive emergency alerts.
  • Evidence and Contact Screen: The application provides an area for emergency information and contact management.

5. How the System Works

  1. The user opens the application.
  2. The user configures emergency contacts.
  3. The application runs its configured monitoring service.
  4. The user says a predefined wake word, such as "Help" or "Aura", or performs a shake gesture.
  5. The system detects the trigger.
  6. The application starts the configured SOS workflow.

6. Design and User Experience

The application focuses on simple navigation, clear emergency actions, readable text, and accessible interaction patterns. The interface is designed to help users understand the available emergency options quickly. The contact and evidence screens organize important information related to the SOS workflow.

7. My Contribution

  • Planned the application flow and SOS activation concept.
  • Designed the user interface and navigation structure.
  • Implemented Android screens using Kotlin.
  • Worked with background service logic for the wake-word workflow.
  • Implemented shake detection using device motion data.
  • Focused on usability and a clear emergency flow.

8. Technologies Used

  • Kotlin
  • Android Studio
  • Android Activity and Service components
  • Device sensors
  • Voice or wake-word detection logic
  • Android UI components

9. Outcome and Learning

This project provided practical experience in Android application development, background services, sensor-based interaction, voice activation concepts, and user-centered design. It also helped explore how mobile technology can support emergency interactions through alternative input methods.

10. Future Improvements

  • Improve wake-word recognition accuracy.
  • Add configurable activation phrases.
  • Improve activation and cancellation feedback.
  • Add location sharing where technically and legally appropriate.
  • Add multilingual support.
  • Reduce accidental activation through extensive testing.
